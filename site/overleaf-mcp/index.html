Is there an Overleaf MCP server? What exists today, and an editor with one built in

Short answer: Overleaf's documentation does not describe an MCP server as of November 2026. What Overleaf does document is a set of AI features inside its own editor. To let Claude or another MCP client work on an Overleaf project, people use third-party servers that go through Overleaf's git integration. A few editors, Aldine among them, ship an MCP server of their own.

Written by the Aldine project, so read it with that in mind. Statements about other products are taken from the linked pages of that product's own documentation. Checked on 24 November 2026.

What Overleaf documents

We looked in three places on 24 November 2026. Overleaf's documentation index lists pages for an AI assistant, Error Assist and an AI table generator, and has no page about an MCP server or a public API for projects. (Overleaf documentation index, as of November 2026) Overleaf's GitHub organization has no repository matching "mcp". (Overleaf on GitHub, search for mcp, as of November 2026) And the AI features page describes no MCP, API or agent integration. (Overleaf docs: AI features, as of November 2026)

One thing can mislead a search. Every page of the documentation site carries the line "Agents can also search and read this documentation through its MCP server." That server answers questions about the help pages. It does not open, read or edit your projects. (Overleaf docs, page header, as of November 2026)

The AI features Overleaf does document

These run inside the Overleaf editor. Overleaf's page lists an AI assistant (a chat panel that can query your project), Error Assist for LaTeX errors, Writefull language suggestions, rewrite and generate tools, TeXGPT, and equation and table generators. It says the features "are available for free within daily limits", and that each use of a feature counts against a daily allowance that resets every 24 hours. (Overleaf docs: AI features, as of November 2026)

The AI assistant is the exception. "The AI assistant is available on the Student, Standard, and Pro plans. It's not included on the Free plan or with Commons access." (Overleaf docs: AI assistant, as of November 2026) On where content goes, Overleaf writes that "Some AI features send content to third-party services, including OpenAI." (Overleaf docs: AI features, as of November 2026)

So if you want an assistant inside Overleaf, that is the documented route. An MCP server answers a different need: you keep working in Claude, Claude Code or another client, and the client reaches into the project.

Third-party MCP servers for Overleaf

These are community projects. They are not made or endorsed by Overleaf. We have not tested them. Each description below comes from the project's own README, and both projects reach Overleaf the same way: through Overleaf's documented git integration, with a git authentication token.

  • OverleafMCP (mjyoo2, MIT licence). The README describes access to Overleaf projects "via Git integration". You supply a project id and a git token created under Account Settings, Git Integration. Its tools list files, read them, parse LaTeX sections and write files or single sections back with a commit message. The tool list has no compile step. The README warns that the token grants full read and write access to the project and should be treated like a password. (OverleafMCP README, as of November 2026)
  • overleaf-mcp-server (YounesBensafia, MIT licence). It keeps a local mirror of the project: it pulls from Overleaf's git remote, edits a file, commits and pushes. Tools are list_files, read_file, write_file, edit_file and sync_project. Its requirements name "An Overleaf plan with Git integration". (overleaf-mcp-server README, as of November 2026)

Other Overleaf MCP projects exist on GitHub. Some of them describe working through a browser session cookie or through Overleaf's web interface rather than a documented integration. We leave those out here.

Before you connect one

  • The git integration is a premium feature on overleaf.com. Overleaf's words: "it will only be available if the project owner has a paid subscription to Overleaf or has been granted access to the feature". (Overleaf docs: Git integration, as of November 2026)
  • Pushes and review comments do not mix well. Overleaf's git page says that "pushes from Git to Overleaf can result in the loss or displacement of track changes and comments", and does not recommend using both actively. An agent that edits by pushing is a git user in that sense. (Overleaf docs: Git integration, as of November 2026)
  • Typesetting happens elsewhere. Neither server above lists a tool that compiles on Overleaf, so checking whether an edit still builds means a local TeX installation or opening the project in the browser.
  • Token handling is on you. How to create and renew git tokens is covered in cloning an Overleaf project with git.

An editor with the MCP server built in

Aldine is an open-source, self-hosted collaborative LaTeX editor. Its MCP server is part of the editor's backend rather than a bridge in front of it, so Claude works on the same live documents your co-authors have open.

  • Read, edit, typeset. Claude reads the file tree and files, edits by replacing exact quoted text, runs latexmk and gets errors back with file and line, and can show the PDF.
  • Every change is a commit. Each write is a git commit authored "Claude", and the editor offers a review of the diff and a one-click revert.
  • Off by default. You turn it on with ALDINE_MCP=1. It is listed in the official MCP Registry since release 1.6.0. (Aldine changelog)

The connector setup, the full tool table and a public demo token are on the LaTeX MCP server page, with the long version in docs/AGENT_API.md. Moving a paper over is a download: export the Overleaf project as a source ZIP and drop it on Aldine's home screen.

Now the limits. Aldine is self-hosted only, and there is no hosted service today. It is young (first release July 2026, 1.0 in October 2026). Review works through comments with suggested edits and git diffs; there are no keystroke-level track changes. Which Claude clients can reach an instance on localhost, and which need a public address, is covered on the MCP page.

When Overleaf is the better choice

  • You want AI help inside the editor you already use. Overleaf's AI features need no extra server, and apart from the AI assistant they are offered for free within daily limits. (Overleaf docs: AI features, as of November 2026)
  • Your co-authors are on Overleaf and moving the paper is not on the table.
  • You do not want to run anything. overleaf.com is hosted; Aldine is not.
  • You rely on track changes. Overleaf has them as a premium feature. (Overleaf docs: track changes, as of November 2026)

Common questions

Does Overleaf have an official MCP server?

Overleaf's documentation does not describe an MCP server as of November 2026, and Overleaf's GitHub organization has no repository named for one. The documentation site has an MCP server of its own, but that one serves the help pages, not your projects.

Can Claude edit my Overleaf project?

Not through anything Overleaf documents for that purpose. Third-party MCP servers do it by cloning the project with Overleaf's git integration, editing the files and pushing them back. On overleaf.com that integration needs a paid plan on the project owner's side.

Is Overleaf's AI assistant free?

Overleaf says its AI features are available for free within daily limits. The AI assistant itself is on the Student, Standard and Pro plans; Overleaf's page says it is not included on the Free plan or with Commons access.

Which LaTeX editor has an MCP server built in?

Aldine, an open-source editor you host yourself, has one. Turn it on with ALDINE_MCP=1 and add the instance to Claude as a connector. Claude can then read and edit files, typeset with latexmk and read the errors, and every change is a git commit authored Claude. The setup is on the LaTeX MCP server page.
