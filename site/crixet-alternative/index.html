Crixet and Prism alternatives: exporting your LaTeX projects and where to take them

Crixet is now part of OpenAI. It became Prism, and OpenAI has announced that Prism will shut down on 1 January 2027. So if you wrote papers in Crixet or Prism, the practical questions are how to get your files out before that date and which editor to continue in. This page answers both, using OpenAI's own instructions for the first.

Written by the Aldine project, so read it with that in mind. Statements about other products are taken from the linked pages of that product's own documentation. Checked on 24 November 2026.

What happened to Crixet

OpenAI announced Prism on 27 January 2026. The announcement says Prism "builds on the foundation of Crixet, a cloud-based LaTeX platform" that OpenAI acquired and "has since evolved into Prism as a unified product." (OpenAI: Introducing Prism, as of November 2026) The old address follows suit: crixet.com answers with a permanent redirect to OpenAI's website (checked on 24 November 2026).

At launch, Prism offered "unlimited projects and collaborators" to anyone with a ChatGPT personal account. (OpenAI: Introducing Prism, as of November 2026)

The same page now opens with a notice headed "Important Prism update". It reads: "Prism will shut down on January 1, 2027." (OpenAI: Introducing Prism, as of November 2026) OpenAI's help article on the migration adds one more fact you should plan around: "After shutdown, all Prism-related data will be deleted." (OpenAI Help: Prism to Codex migration guide, as of November 2026)

Export your projects first

Do this before you pick a new editor. The steps below are the ones OpenAI documents. (OpenAI Help: Prism to Codex migration guide, as of November 2026)

  1. Everything at once. "From the user or workspace menu, open Settings → Data Controls → Export all projects (zip) → Download zip."
  2. One project. Open the project-title menu and choose Export (zip).
  3. Check the archive. Unzip it. The project files arrive with their folder structure. Some projects also contain a conversations folder of JSON files, which the guide describes as kept for reference.
  4. If something failed, look for export-errors.json in the archive and export the affected project again from its own menu.

Two details are easy to miss. A shared project that you do not own exports its files but not your Prism conversation history. And the guide states that "Project history, inline comments, collaborator permissions, and the live Zotero connection do not move", so if you need the comments, copy them out by hand while you still can.

Keep the ZIP somewhere other than your downloads folder. Whatever you choose next, this archive is your copy.

Where to go next

What you need from the next editor depends on how you used Prism. Writing alone with an AI assistant is a different job from co-editing a paper with four people in the browser.

OpenAI's suggested route: Codex

OpenAI's migration guide is written around Codex, which works on the exported files in a local folder. The guide is direct about what that is not: "a local Codex folder is not a shared real-time editor", and "Most multi-file LaTeX projects also need a local TeX toolchain." (OpenAI Help: Prism to Codex migration guide, as of November 2026) That fits a single author who mostly used the assistant. For co-authors editing the same document live, look below.

Overleaf

Overleaf is a hosted LaTeX editor, so there is nothing to install. It can take your export directly: in the project dashboard choose New project, then "Existing project (.zip)", and drop the archive into the upload dialog. There are limits on that upload. Each upload takes up to 180 files (the rest are skipped), single files can be at most 50 MB, and the editable material in a project cannot exceed 7 MB. For a bigger project, Overleaf suggests uploading a subset and adding the remaining files by hand. (Overleaf docs: uploading a project, as of November 2026)

Plan the team size before you move. The free plan lists "1 collaborator per project"; Student and Standard list 10, Pro lists unlimited, and the git, GitHub and Dropbox integrations are on the paid plans. (Overleaf plans, as of November 2026) Prices change; Overleaf's plans page is authoritative.

Aldine, if you would rather host it yourself

Aldine is an open-source (AGPL-3.0) collaborative LaTeX editor that you run on your own server in two Docker containers. It imports a LaTeX project from a ZIP file. That import is built and tested around Overleaf ZIPs and generic ZIPs; we have not tested a Prism export specifically, so check that the right root file was picked after the first typeset.

  • Real-time co-editing with live cursors, and no limit on collaborators.
  • Every project is a real git repository, with branches you create and merge in the browser and push and pull to GitHub, GitLab, Gitea or Forgejo.
  • Review comments with suggested edits.
  • Zotero sync for your library, a group library or one collection, which replaces the Zotero link that does not survive the export. See Zotero with LaTeX.
  • If the AI assistant was what you used most: Aldine has an optional built-in MCP server through which Claude can edit, typeset and commit in a project. See the LaTeX MCP server page. It is a different model from Prism's assistant and it is not an OpenAI product.

The limits matter here, so plainly: Aldine is self-hosted only and there is no hosted service today, so somebody on your side has to operate it. It is also young. The first release was in July 2026 and 1.0 came in October 2026. Review works through comments and git diffs, without keystroke-level track changes. The full list is in the self-hosting guide.

No account, no install. The demo is a shared sandbox and resets every night, so do not leave a real paper there.

When staying on Prism until the end is reasonable

Moving a paper mid-draft costs time. If your submission is due before 1 January 2027 and the co-authors are already working in Prism, finishing there can be the calmer option. Export a copy now anyway, then export again after the last edit. And if you write alone and used Prism mainly for its assistant, OpenAI's own route to Codex keeps you with the same vendor and is documented step by step in the guide linked above.

Common questions

What happened to Crixet?

OpenAI acquired it. OpenAI's announcement of 27 January 2026 says Prism "builds on the foundation of Crixet, a cloud-based LaTeX platform" that OpenAI acquired, and crixet.com now redirects to OpenAI's website. (OpenAI: Introducing Prism, as of November 2026)

When does Prism shut down?

OpenAI's Prism page states: "Prism will shut down on January 1, 2027." Its help article adds that all Prism-related data will be deleted after shutdown. (OpenAI Help: Prism to Codex migration guide, as of November 2026)

Overleaf or Crixet: which should I use now?

Crixet is no longer a separate product; it became Prism, which closes on 1 January 2027. The choice is between a hosted editor such as Overleaf and a self-hosted one such as Aldine. If nobody on your team wants to run a server, Overleaf is the simpler move.

Can I import a Prism export into Overleaf?

Overleaf documents an Existing project (.zip) upload. Its limits apply: up to 180 files per upload, no file over 50 MB, and no more than 7 MB of editable material. A larger project goes in as a subset, with the rest added by hand. (Overleaf docs: uploading a project, as of November 2026)

Does anything carry over besides the files?

Not much. OpenAI's guide says project history, inline comments, collaborator permissions and the live Zotero connection do not move. Some exports include a conversations folder of JSON files, kept for reference. (OpenAI Help: Prism to Codex migration guide, as of November 2026)
