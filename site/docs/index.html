Aldine documentation

Aldine is an open-source, self-hosted collaborative LaTeX editor. The guides on this site cover running it and connecting it to the tools around it. The reference documents live in the repository on GitHub.

Applies to Aldine 0.14.4. Updated on 24 October 2026.

Guides

  • Self-hosting with Docker Compose: the compose file, upgrades and rollback, TeX packages, reverse proxy, backups and compile limits.
  • Single sign-on: OpenID Connect, Google, GitHub, ORCID and passwords, with every variable, the redirect URI and a recipe per provider.
  • LaTeX MCP server: connect Claude to a project so it can read, edit and typeset, and review what it changed.
  • Zotero with LaTeX: three ways to keep a .bib file in sync with a Zotero library.
  • Git with Overleaf: how Overleaf's git integration and GitHub sync work, and how an editor built on git repositories differs.

Overleaf comparisons and questions

  • Overleaf alternatives: the self-hostable options side by side, sourced and dated.
  • Self-hosting Overleaf: what Community Edition includes, how it differs from Server Pro, and where Aldine fits.
  • Overleaf compile timeout: the limit on each plan, why compiles time out, the fixes, and how self-hosted editors set the limit.
  • Overleaf free plan: what the free plan includes, what is paid, and current prices, with sources.

Reference on GitHub

  • README: features, quick start, production deploy and architecture.
  • docs/OIDC.md: OpenID Connect sign-in in full, including moving accounts to a new issuer.
  • docs/AGENT_API.md: the MCP server for the person who runs the instance: credentials, tool reference, security and troubleshooting.
  • docs/SCALING.md: what is and is not built for running past one node.
  • deploy/README.md: the single-VPS runbook, with the table of every configuration variable.
  • CHANGELOG: what changed in each release.

Questions and problems

Ask in GitHub Discussions. To report a vulnerability, follow SECURITY.md.
