## Verdict: RENAME — high confidence

Rename before launch. This is the last moment it costs nothing, and the research shows the name is worse off than the earlier quick check suggested. The three strongest reasons:

1. **The project's most important search query is already owned by a same-space product.** The #1 result for "papyr latex" is [papyr.ai](https://papyr.ai/) — an OCR tool whose entire pitch is *converting handwritten notes to LaTeX*, on an exact-match domain. This is not distant noise like the Undertale character; it is a LaTeX-tooling product sitting permanently on the head query. Users who hear "Papyr… the LaTeX thing" and google it will land on papyr.ai.
2. **Every distribution handle is taken, and the name is being actively re-colonized right now.** papyr.com (grammar-ed site), papyr.io (registered 2021 — verified via whois), papyr.dev, papyr.app, getpapyr.com — all registered. [github.com/papyr](https://github.com/papyr) is an active user with 162 repos, so "papyr github" surfaces them plus jupyter/papyri, papyrs, and a [real-time collaborative Markdown editor named papyrus](https://github.com/FurqanSoftware/papyrus). npm `papyr` and PyPI `papyr` are squatted. Two iOS apps named exactly "Papyr" launched in ~2025 ([document scanner](https://apps.apple.com/us/app/papyr/id6758280008), [PDF/audiobook reader](https://apps.apple.com/us/app/papyr-pdf-audiobooks/id6760125804)) — the mark is getting *more* crowded, not less. Only papyr.sh is free (verified: whois "Domain not found").
3. **Trademark-adjacent exposure in the exact goods class.** [Papyrus Software / ISIS Papyrus](https://www.isis-papyrus.com/) is a 35-year-old vendor of *document creation and processing software* with 2,800+ enterprise customers — near-identical mark, overlapping class. Risk-ranking (not legal advice): low for a free OSS repo, but it becomes real the day Papyr offers hosted SaaS or takes sponsorship; the two live iOS apps also hold common-law claims on the exact string "Papyr" for document apps. QuirkLogic's dead Papyr tablet — literally marketed as "real-time collaboration" — shows the mark has already been used and abandoned once in this semantic space.

Secondary factors that tipped it: pronunciation is genuinely ambiguous (PAY-per? pa-PIE-er? pa-PEER?); anyone who *hears* the name will type "papyrus" or "papier" and land in font/Undertale/stationery noise (verified: "papyr" alone is clean of Undertale noise — the noise attaches to the misspellings people will actually make); and the vowel-dropped "-yr" reads as 2010s Flickr/Tumblr-era styling rather than clever. The papyrus→writing semantic is good, but the truncation keeps the collision cost while shedding some of the meaning.

## If you keep it anyway (mitigations)

- **Register papyr.sh today** — it is the only exact-match domain left (confirmed available). papyr.io/.dev/.app/getpapyr.com are gone.
- Anchor every surface on the two-word phrase: repo description and README H1 = "Papyr — self-hosted collaborative LaTeX editor (open-source Overleaf alternative)". Never fight for the bare term "papyr"; target "papyr latex", "overleaf alternative self-hosted", "collaborative latex editor".
- GitHub topics: `latex`, `overleaf-alternative`, `collaborative-editing`, `self-hosted`.
- npm: `papyr` is squatted (stale API-docs viewer, 2022) — use `papyr-latex` (verified free) or the `@papyr` scope if claimable.
- Accept that the App Store name is unusable if you ever ship a mobile client, and avoid any hosted-commercial move without a trademark screen against ISIS Papyrus.
