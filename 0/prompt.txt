## Bugs / UX issues (ranked)

1. **BLOCKER — "+ New file" with an existing filename silently destroys that file's content.**
   Repro: open a project → sidebar "+ New file" → enter `main.tex` (already exists) → Enter. Actual: no warning, no error, no toast — the inline input just closes and `main.tex` becomes **0 bytes, persisted server-side** (verified after reload: content gone). Expected: reject with "file already exists" or ask to overwrite. Any user creating a file that collides with an existing name loses work instantly. (Git history may allow recovery, but the flow itself must not be destructive-by-default.) This is exactly the kind of thing an HN visitor will hit within minutes.

2. **MAJOR — Unknown routes render a completely blank page.**
   Repro: visit `http://localhost:5173/totally/bogus/route`. Actual: empty background, nothing else — a dead end with no way back except the URL bar. Console: `No routes matched location "/totally/bogus/route"` (×2). Expected: a 404 view with a "Back to projects" link. Contrast: `/p/doesnotexist` handles this well (redirect + toast).

3. **MAJOR — Editor unusable below ~600px; no mobile fallback (X-2).**
   At 375px CSS width: 218px horizontal page overflow; toolbar buttons/selects and pdf-status render off-screen; the code pane computes to 0px width. Even a "best viewed on desktop" notice would beat the broken layout for launch-day phone visitors. Home also overflows 7px at 375 (header `New project` button, `→382px`).

4. **MAJOR (a11y) — Modals are not dialogs.**
   New project / Import from GitHub overlays have no `role="dialog"`/`aria-modal`, don't move focus into the modal on open (activeElement stays on body), and don't trap Tab. Escape does close them. Screen-reader users get no announcement that a modal opened; keyboard users can Tab into the obscured page behind it.

5. **MINOR — "Project not found" toast is duplicated** (two identical stacked toasts from one bad `/p/…` navigation — likely a double-fired effect, e.g. StrictMode-unsafe fetch effect).

6. **MINOR — 768px editor: fixed 230px sidebar leaves a 176px code pane.** No sidebar collapse control at narrow widths; typing in a ~20-char-wide column is impractical on small laptops/split screens.

7. **MINOR (a11y) — Light-theme line numbers contrast 2.21:1** (dark theme is 3.79:1). Fails WCAG even for large text. Muted UI text elsewhere passes (4.66:1 light / 5.93:1 dark).

8. **MINOR (a11y) — Unnamed controls:** "Import ZIP" file input has no accessible name (not announced, though it is in tab order); PDF zoom percentage textbox unlabeled.

9. **POLISH — Sidebar tab strip wraps into two uneven rows** ("Files History Review Fix" / "Cite Zotero") with an awkward gap at default width — reads as unfinished.

10. **POLISH — Native `window.confirm` for project deletion** while everything else uses styled modals/toasts — inconsistent chrome-native dialog in an otherwise polished UI (the wording itself is good: "Delete "QA X-Audit"? This removes the project and its history.").

11. **POLISH — Console noise:** React Router v7 future-flag warnings on every load; duplicate "No routes matched" warnings. No actual errors observed anywhere.
