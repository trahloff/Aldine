## Bugs / UX issues

1. **MAJOR — DOI-imported BibTeX contains raw HTML entity `&amp;amp;`, breaking typeset.** Repro: Cite panel → add DOI `10.1145/3292500.3330701` → entry appended with `booktitle={...Knowledge Discovery &amp;amp; Data Mining}` (raw file verified via API) → actually `\cite{Akiba_2019}` and typeset. Actual: compile fails — Problems panel shows `Error line 42: Misplaced alignment tab character &amp;.` Expected: CrossRef metadata should be HTML-unescaped and LaTeX-escaped (`\&amp;`) before appending. Any DOI whose title/venue contains `&amp;` produces a .bib that un-compiles the project via the app's own headline feature.

2. **MINOR — Reference-lookup error toast is transient and easy to miss.** The "Lookup failed..." toast auto-dismisses in under ~4s with no persistent indication near the identifier field; in one attempt I observed no feedback at all by the time the screenshot was taken. Expected: inline error state on the input, or a longer-lived toast.

3. **MINOR — Zotero "Connect" with an empty key is a silent no-op.** No validation message, no toast, no request fired. Expected: "API key required" inline message.

4. **POLISH — Console noise: `[pdf] render failed RenderingCancelledException` logged at ERROR level** (apps/web `src/components/PdfPane.tsx:97`) on nearly every auto-typeset cycle while typing (7 occurrences in one tab in ~5 min). It's an expected cancellation and should not be `console.error`.

5. **POLISH — Presence avatars have no hover tooltip with the collaborator's name**; the name is only discoverable via the remote cursor flag in the document. Same-browser collaborators also share one identity/color (localStorage-scoped), so avatars are indistinguishable — cosmetic in real cross-user use, but worth a look.
